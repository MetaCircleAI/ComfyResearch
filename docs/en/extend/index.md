# Extend Comfy Research

:::{div} cr-article-lead
Add a Node through the in-repository definition pipeline, then regenerate and
verify the shared backend and frontend contract.
:::

The extension surface is an in-repository API, not a runtime plugin loader.
Definitions, runtime providers, generated metadata, and frontend behavior are
reviewed together so saved graphs and executable Nodes do not drift apart.
